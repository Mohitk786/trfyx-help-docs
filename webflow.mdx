# Install Trfyx on Webflow

Webflow lets you add the Trfyx tracker through your site's custom code settings.

## Add the tracker

<Steps>
  <Step title="Open Site Settings">
    In your Webflow dashboard, select your project and open **Site settings**.
  </Step>
  <Step title="Open Custom Code">
    Go to **Custom Code** and locate the **Head Code** section.
  </Step>
  <Step title="Add the Trfyx snippet">
    Paste the tracking snippet generated for your Trfyx project into the Head Code section. Use your actual Trfyx project identifier and domain configuration.
  </Step>
  <Step title="Save and publish">
    Save the changes and publish the site.
  </Step>
</Steps>

## Verify installation

Open the published website, browse a few pages, and check your Trfyx dashboard for incoming activity. Changes made in Webflow custom code are reflected on the published site, so verify the live domain rather than relying only on Designer preview.
