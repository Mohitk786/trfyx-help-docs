Podia provides settings for adding third-party tracking code. Add the Trfyx tracker using the site-wide code location available in your Podia account.

<Steps>
  <Step title="Log in to Podia">
    Log in to your Podia account and open your site or settings area for third-party code.
  </Step>
  <Step title="Find the header code field">
    Find the field intended for site-wide tracking or header code.
  </Step>
  <Step title="Paste the Trfyx script">
    Paste the Trfyx tracking script into the header code field:

    ```html podia-header.html
    <script
      defer
      data-website-id="YOUR_TRFYX_PROJECT_ID"
      data-domain="your_domain.com"
      src="https://app.trfyx.com/script.js"
    ></script>
    ```

    <Warning>
      Replace `YOUR_TRFYX_PROJECT_ID` with the Website ID from your Trfyx project and `your_domain.com` with the domain you want to track. Keep the script URL as `https://app.trfyx.com/script.js`. Do not copy another project's Website ID.
    </Warning>
  </Step>
  <Step title="Save and publish">
    Save and publish the changes to your Podia site.
  </Step>
  <Step title="Verify installation">
    Visit the published Podia site, test more than the homepage if your site contains multiple routes or pages, and then check your Trfyx dashboard for incoming pageviews.
  </Step>
</Steps>

## Troubleshooting

If traffic is missing, confirm the code was saved in the site-wide tracking location, the site was published after the change, and the Website ID and domain match the Trfyx project you are viewing.
