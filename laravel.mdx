# Add Trfyx to your Laravel project

The recommended approach is to add the tracker to the shared Blade layout so it loads on every page.

## Add the tracker to your layout

Open your main layout, commonly `resources/views/layouts/app.blade.php`, and add the tracker inside `<head>`:

```html
<script
  defer
  data-website-id="YOUR_TRFYX_PROJECT_ID"
  data-domain="your_domain.com"
  src="https://app.trfyx.com/script.js"
></script>
```

<Warning>
  Replace `YOUR_TRFYX_PROJECT_ID` with the Website ID from your Trfyx project and `your_domain.com` with the domain you want to track. Keep the script URL as `https://app.trfyx.com/script.js`. Do not copy another project's Website ID.
</Warning>

Use the Website ID, domain, and script URL provided by Trfyx. Do not hard-code secret server-side API keys into this template.

## Optional: use environment configuration

For cleaner deployments, keep non-secret project configuration in `.env` and expose it through a Laravel config file. This is useful when staging and production use different Trfyx projects.

```php
return [
    'website_id' => env('TRFYX_WEBSITE_ID'),
    'domain' => env('TRFYX_DOMAIN'),
];
```

Then reference the values from your Blade layout.

## Verify installation

1. Deploy the Laravel application.
2. Open the production URL.
3. Navigate through multiple pages.
4. Check the Trfyx dashboard for the incoming visit.

## Troubleshooting

If tracking is missing, verify the layout is actually used by all pages, inspect the browser network panel for blocked requests, check the Website ID and hostname, and make sure your production deployment contains the latest configuration.
