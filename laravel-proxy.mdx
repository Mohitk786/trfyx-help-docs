# Proxy Trfyx with Laravel

Laravel can expose same-origin routes that forward the Trfyx script and events.

## 1. Add routes

In `routes/web.php`:

```php
use Illuminate\Support\Facades\Http;
use Illuminate\Http\Request;

Route::get('/script.js', function () {
    $response = Http::get('https://app.trfyx.com/script.js');

    return response($response->body(), $response->status())
        ->header('Content-Type', 'application/javascript');
});

Route::post('/api/events', function (Request $request) {
    $headers = [
        'Content-Type' => $request->header('Content-Type', 'application/json'),
        'Origin' => $request->getSchemeAndHttpHost(),
        'X-Forwarded-For' => $request->header('X-Forwarded-For', $request->ip()),
    ];

    $response = Http::withHeaders($headers)
        ->withBody($request->getContent(), $request->header('Content-Type', 'application/json'))
        ->post('https://app.trfyx.com/api/events');

    return response($response->body(), $response->status())
        ->header('Content-Type', $response->header('Content-Type', 'application/json'));
});
```

## 2. Update the tracker

```html
<script
  defer
  data-website-id="YOUR_TRFYX_PROJECT_ID"
  data-domain="yourdomain.com"
  src="/script.js"
></script>
```

## 3. Verify

Deploy, reload your production site, and confirm both requests use your domain. Then verify the visit in Trfyx.

<Note>
  If your Laravel application already has `/api/events`, choose a different route and set `data-api-url` to that path.
</Note>
