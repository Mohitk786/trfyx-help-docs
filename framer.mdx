# Add Trfyx to your Framer site

Framer lets you add custom scripts to your published site. The simplest setup is to add the Trfyx tracking script globally so it loads across your pages.

## Add the tracking script

1. Open your Framer project.
2. Open **Site Settings** and find the area for custom code or scripts.
3. Add the Trfyx tracking script to the site-wide `<head>` code.
4. Use the Website ID and domain shown in your Trfyx project settings.
5. Publish the site.

Your script should follow this structure:

```html
<script
  defer
  data-website-id="YOUR_WEBSITE_ID"
  data-domain="your_domain.com"
  src="YOUR_TRFYX_SCRIPT_URL"
></script>
```

Do not copy another project's Website ID or script URL. Use the values generated by your Trfyx workspace.

## Verify installation

1. Open the published Framer site in a normal browser session.
2. Visit several pages.
3. Open your Trfyx dashboard and check for incoming traffic.
4. If you use client-side navigation, verify that navigation between pages is reflected in Trfyx.

## Troubleshooting

If no data appears, check that the script was added globally, the site was republished after the change, the Website ID and domain are correct, and browser extensions or Content Security Policy are not blocking the tracker.
