Framer lets you add custom scripts to your published site. The simplest setup is to add the Trfyx tracking script globally so it loads across your pages.

<Steps>
  <Step title="Open site settings">
    Open your Framer project and go to **Site Settings**.
  </Step>
  <Step title="Add the tracking script">
    Find the area for custom code or scripts and add the Trfyx tracking script to the site-wide `<head>` code. Use the Website ID and domain shown in your Trfyx project settings.

    ```html framer-head.html
    <script
      defer
      data-website-id="YOUR_TRFYX_PROJECT_ID"
      data-domain="yourdomain.com"
      src="https://app.trfyx.com/script.js"
    ></script>
    ```

    <Warning>
      Replace `YOUR_TRFYX_PROJECT_ID` with the Website ID from your Trfyx project and `yourdomain.com` with the domain you want to track. Keep the script URL as `https://app.trfyx.com/script.js`. Do not copy another project's Website ID.
    </Warning>

    Do not copy another project's Website ID or script URL. Use the values generated by your Trfyx workspace.
  </Step>
  <Step title="Publish the site">
    Save the changes and publish your Framer site so the custom code becomes live.
  </Step>
  <Step title="Verify installation">
    1. Open the published Framer site in a normal browser session.
    2. Visit several pages.
    3. Open your Trfyx dashboard and check for incoming traffic.
    4. If you use client-side navigation, verify that navigation between pages is reflected in Trfyx.
  </Step>
</Steps>

## Troubleshooting

If no data appears, check that the script was added globally, the site was republished after the change, the Website ID and domain are correct, and browser extensions or Content Security Policy are not blocking the tracker.
