Vercel v0 can generate React and Next.js applications. Ask v0 to add Trfyx to the root layout and then review the generated code before deploying.

<Steps>
  <Step title="Set up the tracking snippet">
    Use the Trfyx Website ID and domain for the site you want to measure. The script URL is `https://app.trfyx.com/script.js`.

    ```html shared-tracker.html
    <script
      defer
      data-website-id="YOUR_TRFYX_PROJECT_ID"
      data-domain="yourdomain.com"
      src="https://app.trfyx.com/script.js"
    ></script>
    ```

    <Warning>
      Replace `YOUR_TRFYX_PROJECT_ID` with your Trfyx Website ID and `yourdomain.com` with your website's domain. Keep the script URL exactly as shown: do not use a DataFast URL or another project's identifier.
    </Warning>
  </Step>
  <Step title="Ask v0 to add tracking">
    Open your project in v0 and use a prompt similar to this:

    ```text Prompt
    Add Trfyx analytics to my application.
    
    Use https://app.trfyx.com/script.js as the script URL, data-website-id="YOUR_TRFYX_PROJECT_ID", and data-domain="yourdomain.com". I will provide the actual Website ID and domain values.
    
    Integrate the tracker into the root layout (for example, app/layout.tsx for a Next.js App Router project) using the framework's recommended script mechanism. It must load across the entire application and must not be added separately to individual pages.
    
    Keep the tracker installed once. Show me which file you changed and explain how to verify the script and network requests.
    ```
  </Step>
  <Step title="Review and deploy">
    Before deploying, confirm that the generated code includes `https://app.trfyx.com/script.js`, the correct Website ID, and the correct domain. Make sure another copy of the tracker is not already installed.

    Deploy the application through your normal Vercel workflow and open the live URL.
  </Step>
  <Step title="Verify installation">
    1. Visit the live website.
    2. Open browser Developer Tools and check the **Network** tab for the Trfyx script and tracking requests.
    3. Navigate between several routes.
    4. Check [app.trfyx.com](https://app.trfyx.com/) for activity in the matching project.
  </Step>
</Steps>

## Troubleshooting

If no data appears, verify the tracker is in the root layout, the project ID and domain are correct, and Content Security Policy (CSP) is not blocking the script or requests. Confirm you are checking the deployed environment associated with the Trfyx project.
