Firebase Hosting does not directly reverse-proxy arbitrary external destinations. Use a Cloud Function as the proxy and route your hosting paths to it.

<Steps>
  <Step title="Initialize Functions">
    ```bash Terminal
    firebase init functions
    cd functions
    npm install express express-http-proxy
    ```
  </Step>
  <Step title="Create the proxy">
    ```js functions/index.js
    const { onRequest } = require("firebase-functions/v2/https");
    const express = require("express");
    const proxy = require("express-http-proxy");
    
    const app = express();
    app.set("trust proxy", true);
    
    app.use(
      "/script.js",
      proxy("https://app.trfyx.com", {
        proxyReqPathResolver: () => "/script.js",
      }),
    );
    
    app.use(
      "/api/events",
      proxy("https://app.trfyx.com", {
        proxyReqPathResolver: () => "/api/events",
      }),
    );
    
    exports.trfyxProxy = onRequest(app);
    ```
  </Step>
  <Step title="Configure Hosting rewrites">
    Point `/script.js` and `/api/events` to the deployed function in `firebase.json`:

    ```json firebase.json
    {
      "hosting": {
        "rewrites": [
          { "source": "/script.js", "function": "trfyxProxy" },
          { "source": "/api/events", "function": "trfyxProxy" }
        ]
      }
    }
    ```
  </Step>
  <Step title="Update the tracker">
    Replace the default Trfyx script with the proxied path:

    ```html index.html
    <script
      defer
      data-website-id="YOUR_TRFYX_PROJECT_ID"
      data-domain="yourdomain.com"
      src="/script.js"
    ></script>
    ```
  </Step>
  <Step title="Verify installation">
    Deploy and verify the two requests in your browser Network panel. Confirm the visit appears in Trfyx.
  </Step>
</Steps>
