Add the Trfyx tracker from your application's main entry point so it loads once for the whole Vue application.

<Steps>
  <Step title="Add the tracker to the entry point">
    Open `main.js` or `main.ts` and add the tracker before mounting the Vue app:

    <Tabs>
      <Tab title="main.ts">
        ```ts main.ts
        import { createApp } from "vue"
        import App from "./App.vue"
        
        const script = document.createElement("script")
        script.defer = true
        script.src = "https://app.trfyx.com/script.js"
        script.setAttribute("data-website-id", "YOUR_TRFYX_PROJECT_ID")
        script.setAttribute("data-domain", "yourdomain.com")
        document.head.appendChild(script)
        
        createApp(App).mount("#app")
        ```
      </Tab>
      <Tab title="index.html">
        ```html index.html
        <script
          defer
          data-website-id="YOUR_TRFYX_PROJECT_ID"
          data-domain="yourdomain.com"
          src="https://app.trfyx.com/script.js"
        ></script>
        ```
      </Tab>
    </Tabs>

    <Warning>
      Replace `YOUR_TRFYX_PROJECT_ID` with the Website ID from your Trfyx project and `yourdomain.com` with the domain you want to track. Keep the script URL as `https://app.trfyx.com/script.js`.
    </Warning>

    <Tip>
      Install the tracker in the main entry point or shared HTML shell. Do not inject it from individual Vue components; components can mount more than once and create duplicate tracking.
    </Tip>

    <Note>
      If your project uses a standard Vite-generated `index.html`, you can add the script directly to its `<head>` instead. Use only one installation method.
    </Note>
  </Step>
  <Step title="Verify installation">
    Deploy the application and open the live URL. Navigate between several client-side routes and check [app.trfyx.com](https://app.trfyx.com/) for activity in the matching project.

    If nothing appears, inspect the browser's **Console** and **Network** tabs for blocked script or tracking requests.
  </Step>
</Steps>

## Troubleshooting

Confirm the Website ID and domain, verify that the deployed build includes the change, and check whether a Content Security Policy, consent manager, or browser extension blocks the tracker. If pageviews are duplicated, make sure the snippet appears only once.
