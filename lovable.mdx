Ask Lovable to add the Trfyx tracker to your app's shared layout or document head. The tracker must load once across the site, not separately inside each page.

<Steps>
  <Step title="Get the Trfyx tracking values">
    Use your Trfyx Website ID and the domain you want to measure. The tracking script URL is `https://app.trfyx.com/script.js`.

    This is the reference snippet Lovable should implement, adapted to your project's framework:

    ```html shared-tracker.html
    <script
      defer
      data-website-id="YOUR_TRFYX_PROJECT_ID"
      data-domain="yourdomain.com"
      src="https://app.trfyx.com/script.js"
    ></script>
    ```

    <Warning>
      Replace `YOUR_TRFYX_PROJECT_ID` with your Trfyx Website ID and `yourdomain.com` with the domain you want to track. Keep the script URL exactly as shown.
    </Warning>
  </Step>
  <Step title="Ask Lovable to install Trfyx">
    Paste this prompt into your Lovable project:

    ```text Prompt
    Install Trfyx analytics in my application.
    
    Use this tracking script URL: https://app.trfyx.com/script.js
    Use data-website-id="YOUR_TRFYX_PROJECT_ID" and data-domain="yourdomain.com".
    
    Replace those two values with the Trfyx Website ID and domain I provide. Follow this project's framework conventions and add the tracker to the global document head or root layout so it runs across all pages and routes.
    
    Install it once only. Do not add duplicate copies to individual pages or components. Show me the file you changed and explain how to verify that the tracker loads.
    ```

    Review Lovable's changes before publishing. If the app uses React or Next.js, prefer its shared root layout or framework script component rather than adding a raw script to a single page.
  </Step>
  <Step title="Publish the site">
    Review the changes, then publish the site from Lovable.
  </Step>
  <Step title="Verify installation">
    1. Open the public URL in a normal browser tab.
    2. Visit the homepage and several additional routes.
    3. Open [app.trfyx.com](https://app.trfyx.com/) and check that activity appears in the correct Trfyx project.
  </Step>
</Steps>

## Troubleshooting

If only one page is tracked, move the tracker to the global layout. If no data appears, verify the Website ID and domain, inspect the browser's **Console** and **Network** tabs, and check whether Content Security Policy (CSP), consent settings, or browser extensions block the script. Remove any duplicate installation.
