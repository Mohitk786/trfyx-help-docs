Squarespace supports custom JavaScript through Code Injection. The cleanest setup is to add the Trfyx tracker to the site-wide header.

<Steps>
  <Step title="Open Code Injection">
    Log in to Squarespace and open **Settings → Advanced → Code Injection**.
  </Step>
  <Step title="Paste the Trfyx script">
    Paste the Trfyx tracking script into the **Header** field:

    ```html squarespace-header.html
    <script
      defer
      data-website-id="YOUR_TRFYX_PROJECT_ID"
      data-domain="yourdomain.com"
      src="https://app.trfyx.com/script.js"
    ></script>
    ```

    <Warning>
      Replace `YOUR_TRFYX_PROJECT_ID` with the Website ID from your Trfyx project and `yourdomain.com` with the domain you want to track. Keep the script URL as `https://app.trfyx.com/script.js`. Do not copy another project's Website ID.
    </Warning>
  </Step>
  <Step title="Save and publish">
    Replace the placeholders with your Trfyx project values, save the changes, and publish the site.
  </Step>
  <Step title="Verify installation">
    Visit the live Squarespace site, navigate through a few pages, and check your Trfyx dashboard for incoming traffic.
  </Step>
</Steps>

## Troubleshooting

Make sure the script is in the site-wide Header rather than a single page, the changes are published, and the Website ID and domain correspond to the Trfyx project you are checking.

If your Squarespace plan restricts Code Injection, confirm that your plan supports the feature before troubleshooting the script.
