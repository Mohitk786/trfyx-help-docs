Wix lets you add custom tracking code through its Tracking and Analytics settings. This guide walks you through adding the Trfyx tracker to all pages.

<Steps>
  <Step title="Open Tracking and Analytics">
    Open your Wix dashboard or editor and go to **Settings → Tracking & Analytics**.
  </Step>
  <Step title="Add a new tool">
    Choose **Add New Tool** and select the custom-code option.
  </Step>
  <Step title="Paste the Trfyx script">
    Paste the Trfyx tracking script into the code field:

    ```html wix-tracking.html
    <script
      defer
      data-website-id="YOUR_TRFYX_PROJECT_ID"
      data-domain="yourdomain.com"
      src="https://app.trfyx.com/script.js"
    ></script>
    ```

    <Warning>
      Replace `YOUR_TRFYX_PROJECT_ID` with the Website ID from your Trfyx project and `yourdomain.com` with the domain you want to track. Keep the script URL as `https://app.trfyx.com/script.js`. Do not copy another project's Website ID.
    </Warning>
  </Step>
  <Step title="Configure placement">
    Configure the tool to load on **all pages** and place it in the **head**.
  </Step>
  <Step title="Save and publish">
    Save the tool and publish your site.
  </Step>
  <Step title="Verify installation">
    Publish the site, open the live domain, and browse several pages. Then check your Trfyx dashboard for incoming traffic.
  </Step>
</Steps>

## Troubleshooting

If data does not appear, verify that the custom code is enabled on all pages, the code is placed in the head, the site has been published, and the Trfyx Website ID and domain are correct.
