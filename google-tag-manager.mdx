Install Trfyx through Google Tag Manager (GTM) without changing your website's source code. This is a good option when your team already manages analytics and marketing scripts from a central GTM container.

<Note>
  Make sure you have access to the GTM container used by your production website and a Trfyx project ready to receive traffic.
</Note>

<Steps>
  <Step title="Create a new tag">
    Log in to your [Google Tag Manager account](https://tagmanager.google.com/) and select the container used by your website. Click **Tags → New** and give the tag a descriptive name, such as **Trfyx Analytics**.
  </Step>
  <Step title="Add the HTML code">
    Click **Tag Configuration** and select **Custom HTML**. Paste the following JavaScript code into the HTML field:

    ```html GTM custom HTML
    <script>
      (function () {
        var script = document.createElement('script');
        script.defer = true;
        script.setAttribute('data-website-id', 'YOUR_TRFYX_PROJECT_ID');
        script.setAttribute('data-domain', 'yourdomain.com');
        script.src = 'https://app.trfyx.com/script.js';
        document.head.appendChild(script);
      })();
    </script>
    ```

    <Warning>
      Replace `YOUR_TRFYX_PROJECT_ID` and `yourdomain.com` with the values for the Trfyx project you want to track. Do not copy an ID or domain from another project.
    </Warning>

    <Tip>
      Use the Custom HTML tag exactly as shown. The `<script>` wrapper is required because GTM is injecting the tracker into your website. Do not paste only the JavaScript body unless your GTM configuration specifically expects it.
    </Tip>
  </Step>
  <Step title="Set the trigger and publish">
    Click **Triggering**, select **All Pages**, and click **Add**. Then click **Save**, click **Submit** in the top-right corner, and **Publish** the container.
  </Step>
  <Step title="Verify installation">
    After publishing, verify the tag before relying on your analytics data.

    **Test with GTM Preview:** Open **Preview** in Google Tag Manager and enter your production website URL. Confirm that the **Trfyx Analytics** tag fires when the page loads.

    **Verify the live website:** Open your published website in a normal browser window and navigate through a few pages. Then open [app.trfyx.com](https://app.trfyx.com/) and check that incoming activity appears for the correct project.

    <Note>
      Analytics data may take a short amount of time to appear. Make sure you are viewing the correct project, environment, hostname, and reporting date range before assuming tracking is broken.
    </Note>
  </Step>
</Steps>

## Common problems

<AccordionGroup>
  <Accordion title="The tag does not fire in GTM Preview">
    Check that the trigger is set to **All Pages**, the tag is published to the correct container, and the container is installed on the website you are testing.
  </Accordion>

  <Accordion title="Trfyx receives no data">
    Confirm that the project ID and domain are correct. Then check the browser console and Network tab for blocked scripts or requests. A Content Security Policy, consent tool, or browser extension can prevent analytics from loading.
  </Accordion>

  <Accordion title="I see duplicate pageviews">
    Make sure Trfyx is installed only once. Check whether the tracker is also present in your application source code, another GTM tag, a CMS integration, or another analytics integration.
  </Accordion>

  <Accordion title="Should I use GTM and a direct installation together?">
    Normally, no. Choose one installation method for the same website. Installing the tracker through both GTM and your application can result in duplicate collection.
  </Accordion>
</AccordionGroup>

## Security and privacy

<Tip>
  Keep the GTM container restricted to trusted team members. Anyone with permission to publish a container can add or modify scripts that run on your website.
</Tip>

Review your consent requirements and privacy configuration before collecting production user data. If your site uses a strict Content Security Policy, make sure it permits the Trfyx script and collection requests required by your setup.
