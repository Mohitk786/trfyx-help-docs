# Proxy Trfyx with Astro

For Astro SSR or server deployments, expose same-origin routes that forward the Trfyx script and event requests.

## Script route

Create `src/pages/script.js.ts`:

```ts
export async function GET() {
  const response = await fetch("https://app.trfyx.com/script.js");
  return new Response(await response.arrayBuffer(), {
    status: response.status,
    headers: { "Content-Type": "application/javascript" },
  });
}
```

## Event route

Create `src/pages/api/events.ts` and forward the request body to `https://app.trfyx.com/api/events` while preserving the visitor IP.

```ts
export async function POST({ request, clientAddress }) {
  const body = await request.arrayBuffer();
  const response = await fetch("https://app.trfyx.com/api/events", {
    method: "POST",
    headers: {
      "Content-Type": request.headers.get("content-type") || "application/json",
      "Origin": new URL(request.url).origin,
      "X-Forwarded-For": request.headers.get("x-forwarded-for") || clientAddress,
    },
    body,
  });

  return new Response(await response.arrayBuffer(), { status: response.status });
}
```

## Update the tracker

```html
<script
  defer
  data-website-id="YOUR_TRFYX_PROJECT_ID"
  data-domain="yourdomain.com"
  src="/script.js"
></script>
```

<Note>
  For a fully static Astro site, use [Managed Proxy](/managed-proxy) instead of adding server routes.
</Note>
